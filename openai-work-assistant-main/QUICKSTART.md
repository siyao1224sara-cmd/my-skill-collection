# 🚀 Quick Start Guide

## Get Started in 3 Steps

### Step 1: ✅ Verify Installation

Your skill is here:
```
~/.claude/plugins/custom/naiba-openai-work-assistant/
```

### Step 2: 🔄 Restart Claude Code

**Important!** Quit and reopen Claude Code to load the skill.

### Step 3: 💬 Start Using!

Just talk to Claude normally. The skill activates automatically.

## 📚 All Commands

| Command | What It Does |
|---------|--------------|
| `help` | Show help |
| `show [role] prompts` | Browse prompts by role |
| `use "[prompt name]"` | Use specific prompt |
| `test` | Test if skill is loaded |

---

## 🎓 How It Works

1. **You type** a task in English or Chinese
2. **Skill detects** your role and language
3. **Finds best** matching prompts (from 201 options)
4. **Guides you** through using it
5. **Generates** professional results

---

## 🐛 Troubleshooting

**Skill not working?**
1. Restart Claude Code (fully quit and reopen)
2. Check folder exists: `ls ~/.claude/plugins/custom/naiba-openai-work-assistant/`

**Wrong language?**
- Be explicit: "用中文" or "in English"

**Wrong role detected?**
- Provide context: "As a product manager..."
- Or browse: "Show me product prompts"
