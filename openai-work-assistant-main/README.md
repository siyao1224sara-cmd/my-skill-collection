## ✨ Quick Overview

### 📦 What Is This?

A powerful Claude Code plugin with **230+ professional prompts** from OpenAI Academy across **10 professional roles**. Features smart role detection and intelligent prompt recommendations.

### 🎯 Key Features

- 🧠 **Smart Role Detection** - Automatically identifies your role
- 🔍 **Intelligent Matching** - Finds the best prompts for your task
- 🌐 **Bilingual Support** - English and 中文
- 📂 **3 Usage Modes** - Smart, Browse, Direct
- ⚡ **Parameter Extraction** - Minimizes back-and-forth

### 📊 Supported Roles

**Sales** • **Customer Success** • **Product** • **Engineering** • **HR** • **IT** • **Management** • **Executive** • **Government IT** • **General**

### 🚀 Quick Install

```bash
git clone https://github.com/zstmfhy/naiba-openai-work-assistant.git
cp -r naiba-openai-work-assistant ~/.claude/plugins/custom/
# Restart Claude Code
```
